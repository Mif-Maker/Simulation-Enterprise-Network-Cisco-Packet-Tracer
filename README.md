Proyek ini merupakan simulasi perancangan dan implementasi jaringan perusahaan berskala enterprise menggunakan Cisco Packet Tracer dengan arsitektur Collapsed Core (Multilayer Switch Layer 3 SVI). Desain jaringan menerapkan segmentasi VLAN terstruktur untuk enam departemen internal (Management, Production, Warehouse, Quality Control, Finance, dan IT), segmen khusus Guest Wi-Fi (VLAN 70), segmen Voice khusus IP Phone (VLAN 80), segmen Server Farm terdedikasi (VLAN 90), segmen Device Management SSH (VLAN 99), serta segmen khusus CCTV Surveillance (VLAN 100).
Untuk mematuhi prinsip desain hierarkis dan isolasi keamanan tinggi, NVR-SERVER (192.168.11.35) dan IT-SERVER (192.168.11.39) ditempatkan secara mandiri pada segmen khusus VLAN 90 (Server Farm — 192.168.11.32/28) dan dihubungkan langsung ke SW-CORE melalui port fisik GigabitEthernet1/0/9 dan GigabitEthernet1/0/11 yang dikonfigurasi sebagai access port VLAN 90. NVR-SERVER merepresentasikan pusat monitoring dan penyimpanan rekaman CCTV secara konseptual, sedangkan IT-SERVER menyediakan layanan terpusat meliputi DHCP Server (dengan mekanisme DHCP Relay ip helper-address), DNS, HTTP intranet, FTP (dengan pembatasan hak akses RBAC), serta TFTP.
Lalu lintas suara IP Phone dipisahkan ke VLAN 80 (192.168.11.0/27) dengan layanan Call Manager Express (CME) yang dijalankan pada Edge Router R1 (192.168.11.129) melalui jalur Point-to-Point internal (192.168.11.128/30). Keamanan jaringan diterapkan secara berlapis (Defense-in-Depth): pengamanan access layer menggunakan Port Security (Sticky MAC, Dynamic MAC dengan aging time 2 menit, batas maximum MAC, violation mode restrict/shutdown), PortFast, BPDU Guard, serta penutupan seluruh port kosong; sementara penyaringan lalu lintas antar-VLAN dan isolasi Guest Wi-Fi maupun CCTV dikendalikan langsung pada SVI SW-CORE menggunakan Extended Access Control List (ACL) dan Identity Access Control (VTY SSH).
