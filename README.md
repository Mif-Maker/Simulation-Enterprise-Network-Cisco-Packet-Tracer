Proyek ini merancang dan mengimplementasikan infrastruktur jaringan perusahaan berskala menengah pada Cisco Packet Tracer menggunakan topologi hierarchical star (Collapsed Core). Jaringan dibagi menjadi 10 segmen VLAN: enam departemen internal (VLAN 10–60), Guest Wi-Fi (VLAN 70), Voice IP Phone (VLAN 80), Server Farm terisolasi (VLAN 90), serta CCTV Surveillance (VLAN 100).
Inter-VLAN Routing dijalankan secara terpusat di Layer 3 melalui Switch Virtual Interface (SVI) pada Multilayer Switch M-SW (Cisco 3650-24PS). Dua server utama—NVR-SERVER (192.168.11.35) dan SERVER (192.168.11.39)—ditempatkan pada VLAN 90 dan terhubung langsung ke port GigabitEthernet pada M-SW. SERVER menangani layanan DHCP (melalui ip helper-address), DNS, HTTP Intranet, dan FTP, sementara Router R1 (Cisco 2911) berfungsi sebagai Edge Router (NAT Overload menuju ROUTER-ISP ISR4331 dengan Loopback0 8.8.8.8/32) sekaligus Call Manager Express (CME) untuk 17 unit Cisco IP Phone 7960.
Catatan Batasan Simulator: Karena Cisco Packet Tracer tidak mendukung streaming/perekaman video CCTV secara penuh, unit kamera direpresentasikan oleh Laptop-PT/Webcam pada VLAN 100 dan NVR-SERVER direpresentasikan oleh Server-PT. Pengujian difokuskan pada konektivitas L2/L3, trunking 802.1Q, SVI routing, DHCP Relay, VoIP CME, isolasi Extended ACL, dan Port Security.
